# Projeto Integrador - AgroJava

Atividade desenvolvida em Java para a disciplina de Lógica de Programação e Algoritmos.

## Sobre o projeto

O programa simula o controle de informações agrícolas e o monitoramento de talhões de uma propriedade rural.

Durante a execução, o sistema:

- Permite cadastrar a quantidade de chuva de 7 dias;
- Calcula a média semanal de chuva;
- Identifica o dia com maior quantidade de chuva;
- Permite cadastrar a umidade dos talhões em uma matriz 4x4;
- Exibe o mapa de umidade do campo;
- Identifica os talhões com umidade abaixo de 30%;
- Exibe um relatório de alertas de irrigação;
- Mantém o menu disponível até que o usuário escolha a opção de sair.

## Conteúdos utilizados

- Entrada de dados com `Scanner`;
- Arrays unidimensionais;
- Matrizes bidimensionais;
- Estruturas de repetição `for` e `do-while`;
- Estruturas condicionais `if-else`;
- Estrutura de seleção `switch-case`;
- Contadores e acumuladores;
- Cálculo de médias;
- Comparação de valores.
